- `onBlur` switches to display mode when value exists
- Default starts in edit mode (isEditing = true)

## Architecture Decisions

### Step Validation Pattern (Option A)
- stepValidation object maps step index to validation rules
- Each rule has:
  - `fields`: Array of card property names to check
  - `requireAll`: If true, all fields must have values (every), else any (some)
  - `message`: Warning message logged on failure

### UIComponent Slot Design
- Named slots for explicit edit/display control
- Slot props pass through component state/methods
- Edit button always rendered by component (not in slot)
- Default uses DaisyUI floating label
